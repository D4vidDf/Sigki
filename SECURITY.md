# Security Policy

## Supported Versions

SigKi is committed to keeping your utility experience secure and private. Security updates are provided for the current stable release.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of SigKi seriously. If you believe you have found a security vulnerability, please report it to us as follows:

1. **Do not** create a public GitHub Issue for security vulnerabilities.
2. Please report the vulnerability by opening a **GitHub Security Advisory** in the repository or by contacting the maintainer directly via GitHub profile details.
3. Provide a detailed description of the issue, including steps to reproduce it.

### What to Expect
- **Response Time**: You can expect an initial acknowledgement of your report within 48–72 hours.
- **Updates**: We will provide status updates at least once a week while the issue is being investigated and fixed.
- **Public Disclosure**: Once the vulnerability is resolved, a new version will be released, and we will coordinate public disclosure through GitHub Security Advisories.

Thank you for helping keep SigKi secure for everyone!
